# Production readiness decision

Audit ID: `ADM-AUDIT-2026-10-21`<br>
Audit began: 2026-10-21 UTC<br>
> **Current candidate — 2026-10-24:** RC5 Release 68 (`0.0.1rc5-68`) is built from root/package source commit `4077c4ddb9d233682961d36c3570c63e70eb6405`; exact component pins, CI, native RPM builds, NEVRAs and hashes are in [`release68-candidate.md`](evidence/release68-candidate.md). R68 scoped Single-Node scenarios have run on all four x86_64 OSes. A real three-guest AlmaLinux 10.2 Multi-Node lab passed scoped explicit placement/replay/runtime/cleanup on both workers, a three-client same-key idempotency race, and the #267 active-worker conflict/idle-worker removal regression; same-guest re-enrollment also passed. The race converged from an unavailable cold-start sample to healthy/available and HTTP 200, consistent with the #236 `--wait` contract. See [`release68-alma-multinode-placement.md`](evidence/release68-alma-multinode-placement.md), [`release68-alma-multinode-concurrent-idempotency.md`](evidence/release68-alma-multinode-concurrent-idempotency.md) and [`release68-alma-multinode-node-removal.md`](evidence/release68-alma-multinode-node-removal.md). These are scoped results only; #267 remains open with `fix-proposed`.

The release gate remains four x86_64 OSes × two topologies = **eight cells**. Completion is **0/8** because no cell has completed its full catalog on R68. Single-Node and Multi-Node are both **NOT VALIDATED** for production. Earlier R67 and R66 runs are candidate-specific historical evidence and earn no R68 matrix credit. ARM64 remains Tier 2 and non-blocking.

Complete every common candidate/evidence gate and every topology-specific check in the [per-cell PASS checklist on issue #200](https://github.com/admiral-project/admiral/issues/200#issuecomment-6374384636) for all eight cells on one unchanged candidate. Measure performance without inventing thresholds. Any required source/RPM fix creates a new candidate and invalidates affected runtime evidence.
