# Release 63 targeted Rocky Single-Node progress — invalidated

**Status: INVALIDATED for release credit; 0/8 matrix cells completed.** Release 63 was built with normal dependency resolution and installed on a fresh Rocky Linux 10.2 x86_64 Single-Node guest. Its named runtime probes are retained as diagnostic evidence. The subsequent Fedora Rawhide 46 build exposed #262: the pinned SQLAlchemy spec did not package Python 3.15's lowercase `.dist-info` directory. Under the candidate invalidation rule, no R63 probe validates the current candidate. The R64 fix is proposed and the new release is not yet built or installed.
